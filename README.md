## About

I like problems where the output has to be exactly right. My aviation work is a
good example — an operational flight plan is a working document, so a fuel
figure that is twenty pounds out is simply wrong, not close enough. That
constraint is what got me interested in parsing, deterministic transforms and
print-accurate rendering. Alongside it I build conventional web applications,
and I am steadily working through the computer science fundamentals underneath
all of it.
